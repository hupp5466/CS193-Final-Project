# F1 Pitstop Game
A java based F1 game that simulates race pitstop strategy. 

## The Reason
I am a massive Formula 1 Fan, and one of the best parts about watching the races live is trying to figure out what tire strategy the teams are going for. I want to try and build a small project that allows the user to try and figure out what is the best strategy given a scenario. 

## How it works
![System diagram] (docs/Diagram.png)

Using Java and race simulation while prompting the user to decide on what to do in pitstops 

## Tech Stack
I will use the basic java programming that was taught in cs180, like io.readln, random, arraylists, string format, printwriter. 
My data will be stored in the runtime memory, once the program is exited there will be no way to save the session, however using print writer I will store the score for each game inside a file called scores.txt. 
I will not be pulling any API's as I will be creating the strategy game inside java and it will be played entirely in the terminal.
